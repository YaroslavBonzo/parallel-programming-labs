## Задание
Модифицировать программу из л/р №1 для параллельной работы по технологии MPI. Провести серию экспериментов с разными размерами матриц (примерно 200, 400, 800, 1200, 1600, 2000), с разным количеством вычислительных ядер (1, 2, 4, 8 и т.д.).

------------------------------------------------------------------------

## Ход работы

Была реализована MPI-версия программы для перемножения квадратных матриц. Матрица A распределяется между процессами с помощью ```MPI_Scatter```, матрица B передаётся всем процессам через ```MPI_Bcast```, после чего выполняется локальное умножение и сбор результата на главном процессе с помощью ```MPI_Gather```.

Для генерации входных данных использовалась отдельная программа-генератор. Для автоматизации экспериментов был написан Python-скрипт, который запускал программу с разным числом процессов (1, 2, 4, 8, 16) и различными размерами матриц. По результатам измерений построен график зависимости времени выполнения от числа процессов.
