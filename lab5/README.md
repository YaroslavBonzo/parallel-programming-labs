## Вывод

Параллельная версия программы умножения матриц с использованием MPI была успешно реализована и запущена на суперкомпьютере «Сергей Королёв». Проведённые эксперименты показали, что с увеличением числа процессов время выполнения уменьшается, особенно для матриц большого размера.

Таким образом, использование MPI и вычислительных ресурсов суперкомпьютера позволяет значительно ускорить выполнение ресурсоёмких задач, несмотря на накладные расходы на обмен данными между процессами.
